# Headscale Gateway para Home Assistant

Muestra en Home Assistant el estado de un servidor Headscale Gateway existente.

[Abrir Headscale Gateway en el Marketplace](https://my.home-assistant.io/redirect/marketplace_repository/?owner=Gente-del-Condado&repository=headscale-gateway-ha&category=integration)

En Home Assistant 2026.11 o posterior, abre **Ajustes → Marketplace**, añade este repositorio como **Integración** y pulsa **Instalar**. Después abre **Ajustes → Dispositivos y servicios → Añadir integración** y busca **Headscale Gateway**.

Las aplicaciones de Home Assistant OS se distribuyen por separado en [Mis-app](https://github.com/Gente-del-Condado/Mis-app).

Forgejo publica esta distribución automáticamente a partir de la integración del proyecto de origen.
